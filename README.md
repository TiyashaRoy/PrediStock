# 📈 PrediStock

AI-Based Stock Price Prediction System

## About the Project

PrediStock is an intelligent stock market
analysis and prediction platform.

It uses historical market data, LSTM deep
learning and news sentiment analysis to
forecast stock price trends.

## Features

- Historical stock price analysis
- LSTM-based stock forecasting
- News sentiment analysis
- Interactive dashboard
- Multi-stock comparison
- Data visualization

## Technologies Used

- Python
- TensorFlow / Keras
- LSTM
- Pandas
- NumPy
- Streamlit
- Plotly
- Yahoo Finance API

## Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
